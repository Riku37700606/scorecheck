# scorecheck

![test](https://github.com/Riku37700606/scorecheck/actions/workflows/test.yml/badge.svg)

標準入力からテストの点数を読み込み、成績の集計を行うLinuxコマンドです。

複数人のテストの点数を入力することで、平均点や合格率などを簡単に確認できます。手作業で集計する手間を減らすことを目的としています。

## 機能

- 受験者数の集計
- 平均点の計算
- 最高点・最低点の取得
- 合格者数・不合格者数の集計
- 合格率の計算
- 合格基準の変更
- 不正な入力に対するエラー処理

## インストール方法

以下のコマンドを実行してください。

```bash
git clone https://github.com/Riku37700606/scorecheck.git
cd scorecheck
chmod +x scorecheck
```

## 使用方法

点数を1行に1つずつ標準入力に与えてください。

点数は0〜100点の範囲で入力してください。
小数の点数にも対応しています。

### 基本的な使い方

合格基準の初期値は60点です。

```bash
printf "80\n45\n90\n60\n55\n" | ./scorecheck
```

実行結果：

```text
受験者数: 5人
平均点: 66.0点
最高点: 90.0点
最低点: 45.0点
合格基準: 60点
合格者数: 3人
不合格者数: 2人
合格率: 60.0%
```

### 合格基準を変更する場合

引数に合格基準を指定できます。

以下は合格基準を80点に設定する例です。

```bash
printf "80\n45\n90\n60\n55\n" | ./scorecheck 80
```

実行結果：

```text
受験者数: 5人
平均点: 66.0点
最高点: 90.0点
最低点: 45.0点
合格基準: 80点
合格者数: 2人
不合格者数: 3人
合格率: 40.0%
```

### ファイルから読み込む場合

点数を記録したファイルを作成します。

```bash
printf "80\n45\n90\n60\n55\n" > scores.txt
```

リダイレクトを利用することで、ファイルから点数を読み込めます。

```bash
./scorecheck < scores.txt
```

### 他のコマンドとの連携

seqコマンドとパイプを利用することもできます。

```bash
seq 50 10 100 | ./scorecheck
```

## エラー処理

以下の場合は標準エラー出力にエラーメッセージを表示します。

- 数値以外の点数が入力された場合
- 点数が0〜100点の範囲外の場合
- 空行が入力された場合
- 点数が入力されなかった場合
- 合格基準が数値でない場合
- 合格基準が0〜100点の範囲外の場合
- 引数が2つ以上指定された場合

正常終了時の終了ステータスは0、異常終了時は1です。

## 必要なソフトウェア

- Python
  - テスト済みバージョン：3.10〜3.14
- Bash（テストの実行に使用）

Pythonの外部ライブラリは必要ありません。

## テスト環境

- Ubuntu 24.04
- GitHub Actions（ubuntu-latest）

## テスト

以下のコマンドでテストを実行できます。

```bash
bash test.bash
```

すべてのテストに成功した場合は、OKと表示されます。

GitHub Actionsを利用して、複数のPythonバージョンで自動テストを実行しています。
